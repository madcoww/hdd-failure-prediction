# Backblaze HDD 데이터 개요

## 1. 핵심 컬럼

**선정 초안** — 30일 안에 고장 날 디스크를 찾기 위해, 고장수 상위 20종 HDD가 모두 기록한 SMART 13개 중 아래 두 개를 핵심으로 골랐다.

| 컬럼 | 설명 | 단위 |
|---|---|---|
| **`smart_5_raw`** | 재할당 섹터 수. 디스크가 고친 불량 칸의 개수. 칸이 망가지면 예비 칸으로 옮겨 쓰는데, 옮긴 횟수가 늘수록 망가지고 있다는 뜻이다 | 개 |
| **`smart_198_raw`** | 오프라인 복구 불가 섹터 수. 검사했더니 못 고친 불량 칸의 개수. 올라가면 손상이 심해졌다는 뜻이다 | 개 |

- 고장 난 디스크 중 **29.9%**는 두 값이 관측 기간 내내 0이었다. 이런 디스크는 이 두 값으로 고장 신호를 잡을 수 없어서, 가동시간·온도 같은 다른 컬럼도 함께 쓴다.

## 2. 전체 컬럼

고장 수 상위 HDD **20종**은 전체 HDD 75종의 디스크 중 **87.38%**, 고장 디스크 중 **94.31%**를 포함한다.

| 범위 | 제품 종류 | 디스크 수 | 전체 HDD 대비 | 고장 디스크 수 | 전체 고장 대비 |
|---|---:|---:|---:|---:|---:|
| 전체 HDD | 75종 | 386,919개 | 100% | 10,518개 | 100% |
| 분석 대상 | 20종 | 338,083개 | **87.38%** | 9,920개 | **94.31%** |

분석 데이터는 **기본 정보 6개 + 20종 공통 SMART raw 13개 = 총 19개 컬럼**이다.

| 컬럼 | 설명 | 단위 |
|---|---|---|
| `date` | 관측 날짜 | 년-월-일 |
| `serial_number` | 디스크 고유 식별자(디스크마다 다른 번호) | 해당 없음 |
| `model` | HDD 제품명 | 해당 없음 |
| `capacity_bytes` | 디스크 용량 | byte |
| `failure` | 그날 고장 났는지 표시. 30일 안에 고장 날지 맞히는 정답을 만들 때 쓴다 | 0/1 |
| `datacenter` | 디스크가 있는 데이터센터 코드 | 해당 없음 |
| `smart_1_raw` | 읽기 오류와 관련된 값 | 제조사별로 다름 |
| `smart_3_raw` | 디스크가 회전을 시작하는 동작과 관련된 값 | 제조사별로 다름 |
| `smart_4_raw` | 디스크가 시작·정지한 횟수 | 회 |
| **`smart_5_raw`** | 재할당 섹터 수. 디스크가 고친 불량 칸의 개수 | 개 |
| `smart_7_raw` | 헤드가 원하는 위치를 찾는 동작과 관련된 값 | 제조사별로 다름 |
| `smart_9_raw` | 누적 가동시간. 디스크가 켜져 있던 총 시간 | 시간(h) |
| `smart_10_raw` | 디스크 회전을 다시 시도한 것과 관련된 값 | 제조사별로 다름 |
| `smart_12_raw` | 전원이 켜진 횟수 | 회 |
| `smart_192_raw` | 갑자기 전원이 꺼져 헤드를 급히 치운 것과 관련된 횟수 | 회(집계 방식은 제조사별로 다름) |
| `smart_193_raw` | 헤드를 올리고 내린 횟수 | 회 |
| `smart_194_raw` | 관측일에 디스크 센서로 잰 온도(순간 값) | ℃ |
| **`smart_198_raw`** | 오프라인 복구 불가 섹터 수. 검사했더니 못 고친 불량 칸의 개수 | 개 |
| `smart_199_raw` | 디스크와 연결선 사이 데이터 전송 오류(CRC) 횟수 | 회 |

## 3. 데이터 제공사가 고장과 관련 있다고 꼽은 SMART 5개

| 컬럼 | 설명 | 단위 |
|---|---|---|
| `smart_5_raw` | 재할당 섹터 수. 디스크가 고친 불량 칸의 개수 | 개 |
| `smart_187_raw` | 보고된 복구 불가 오류 수. 읽기를 시도했지만 끝내 복구하지 못한 오류 횟수 | 회 |
| `smart_188_raw` | 명령 시간 초과. 디스크가 명령에 제때 응답하지 못한 것과 관련된 값 | 제조사별로 다름 |
| `smart_197_raw` | 보류 중인 섹터 수. 불량이 의심돼 확인을 기다리는 칸의 개수 | 개 |
| `smart_198_raw` | 오프라인 복구 불가 섹터 수. 검사했더니 못 고친 불량 칸의 개수 | 개 |

- 5개 중 하나라도 값이 0보다 크면: 고장 디스크의 **76.7%**, 정상 디스크의 **4.2%**가 해당한다.

출처: [Backblaze, What SMART Stats Indicate Hard Drive Failures](https://www.backblaze.com/blog/what-smart-stats-indicate-hard-drive-failures)

## 4. 데이터 구조

- **출처** — Backblaze(미국 클라우드 저장 서비스 회사)가 자사 데이터센터의 HDD 기록을 공개한 Drive Stats.
- **기간** — 2024-04-01~2026-06-30, 821일.
- **관측 단위** — 1행은 디스크 1개의 하루 기록. 시리얼별 날짜순으로 연결하면 시계열이 된다.
- **고장 수** — 디스크별 첫 고장 기준.
