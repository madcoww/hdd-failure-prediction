# Backblaze HDD 데이터 개요

## 1. 핵심 컬럼

**선정 초안** — 향후 30일 내 HDD 고장을 예측하기 위해 공통 SMART 13개 중 다음 두 지표를 핵심 후보로 선정했다.

| 핵심 후보 | 의미 | 단위 | 선정 이유 |
|---|---|---|---|
| **`smart_5_raw`** | 재할당 섹터 수 | 섹터 관련 개수 | 불량 섹터를 예비 영역으로 대체한 기록으로 손상 상태를 파악할 수 있다. 고장 예정·정상 집단의 효과 크기 중앙값이 **0.540**으로 가장 컸다. |
| **`smart_198_raw`** | 오프라인 복구 불가 섹터 수 | 섹터·검사 관련 개수 | 검사에서 복구하지 못한 섹터 관련 기록이다. 효과 크기 중앙값이 **0.232**로 두 번째로 컸다. |

현재 값·0 초과 여부·최근 변화량을 입력 후보로 검증한다. 두 지표가 끝까지 0인 고장 디스크도 **29.9%** 있어, 가동시간·온도 등 다른 지표를 함께 검토한다. EDA v2의 조건부 후보는 **4·5·9·12·193·194·198·199의 8개**이며, 최종 입력은 검증 성능으로 결정한다.

## 2. 전체 컬럼

고장 수 상위 HDD **20종**은 전체 HDD 75종의 디스크 **87.38%**, 고장 디스크 **94.31%**를 포함한다.

| 범위 | 제품 종류 | 디스크 수 | 전체 HDD 대비 | 고장 디스크 수 | 전체 고장 대비 |
|---|---:|---:|---:|---:|---:|
| 전체 HDD | 75종 | 386,919개 | 100% | 10,518개 | 100% |
| 분석 대상 | 20종 | 338,083개 | **87.38%** | 9,920개 | **94.31%** |

분석 데이터는 **기본 정보 6개 + 20종 공통 SMART raw 13개 = 총 19개 컬럼**이다.

| 컬럼 | 설명 | 단위 |
|---|---|---|
| `date` | 관측 날짜 | 년-월-일 |
| `serial_number` | 디스크 고유 식별자 | 해당 없음 |

| `capacity_bytes` | 디스크 용량 | byte |

| `datacenter` | 데이터센터 식별 코드 | 해당 없음 |
| `smart_1_raw` | 읽기 오류 관련 원시 지표 | 제조사별 인코딩 |
| `smart_3_raw` | 회전 시작 관련 원시 지표 | 제조사별 인코딩 |
| `smart_4_raw` | 시작·정지 횟수 | 회 |
| **`smart_5_raw`** | 재할당 섹터 수 | 섹터 관련 개수 |

## 3. 데이터 구조

- **출처** — Backblaze Drive Stats의 실제 데이터센터 HDD 기록.
- **기간** — 2024-04-01~2026-06-30, 821일.
- **관측 단위** — 1행은 디스크 1개의 하루 기록. 시리얼별 날짜순으로 연결하면 시계열이 된다.
